# Marrow

Brunswick (Melbourne) strength gym landing — barbell club on Sydney Road.
Powerlifting and strength. Not a 24-hour cardio box, not yoga, not physio.

Live demo: https://marrow.little.website/

Built with Astro 5 (static output) and a plain CSS design system. No CMS, no auth,
no payments, no membership checkout — contact goes straight to `mailto:sales@little.cloud`.

## Quick start

```sh
bun install
bun run dev
bun run build
bun run preview
```

## Customise

Copy and section flags live in **src/data/site.ts**. Brand tokens in **src/styles/tokens.css**.
